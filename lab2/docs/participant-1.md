# Участник 1 — ядро СУБД и хранение

Реализованы:
- Модели Database, Table, Column, Row
- Типы данных и валидация
- Первичные и внешние ключи
- CRUD
- JSON-сериализация
- Восстановление при запуске
- Тесты ядра

Основные классы:
- `DatabaseEngine` — интерфейс операций
- `DefaultDatabaseEngine` — реализация
- `Database` — набор таблиц
- `Table` — схема и строки
- `JsonStorageManager` — работа с JSON
