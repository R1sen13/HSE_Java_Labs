# MusicDB

Учебная реализация упрощённой реляционной СУБД на Java.

## Возможности
- INTEGER, DOUBLE, STRING, DATE, BOOLEAN
- Первичные и внешние ключи
- CRUD-операции
- Проверка типов и ограничений
- Сохранение и восстановление JSON
- Атомарная замена файла хранилища

## Сборка и тестирование

```bash
mvn test
```

## Структура
- `core` — модели и логика базы данных
- `storage` — сохранение и загрузка
- `docs` — документация

## Предметная область

Музыкальная библиотека: artists, albums, songs.

SQL-парсер, CLI и индексы разрабатываются другими участниками команды.
